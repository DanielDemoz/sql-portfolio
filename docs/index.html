How it is tested

Every push loads the schema into PostgreSQL 16 and runs every window-function example against it.

Checked automatically

  • The university schema creates all tables, indexes and views without errors.
  • All 9 window-function examples run against that schema without errors.
  • One example used PERCENTILE_CONT ... OVER (), which PostgreSQL does not allow. It was rewritten with a CTE.

Not checked

  • The customer analytics file needs an e-commerce schema that is not in the repository. Adapt the table names before running it.
  • There is no sample data, so query results are not checked, only that the SQL runs.
